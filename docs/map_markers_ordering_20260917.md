# 地图/活动 Tab 列表排序规则（2026-09-17）

接口：`GET /api/v1/map/markers`（首页地图与「活动 Tab 列表页」共用数据源）

## 排序规则

1. **活动在前，商家（场地）在后**：返回列表中活动类 marker 排在场地类 marker 之前。
2. **活动按距当前时间最近优先**：
   - 未开始的活动：开始时间距现在越近越靠前；
   - 正在进行中的活动（开始时间已过、未结束）：开始越早越靠后；
   - 实现：`ORDER BY ABS(UNIX_TIMESTAMP(a.start_time) - UNIX_TIMESTAMP()) ASC, a.id DESC`；
   - 注：已结束活动被 `end_time >= now` 过滤，不参与排序。
3. 场地之间仍按创建时间倒序。

## 行为说明

- 活动**仍按 `end_time >= now` 过滤**：已结束（过期）活动不出现在列表/地图中（2026-09-17 曾短暂移除该过滤，同日复原）。
- 活动状态仍需为已上线（`status=3`）且未隐藏（`is_hidden=0`），主办方需已审核且启用。
